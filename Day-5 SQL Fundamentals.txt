## 💻 LeetCode Problems Solved

### 1. 1757. Recyclable and Low Fat Products

**Topics:** `SELECT`, `WHERE`, `AND`

**Problem Objective:**  
Retrieve the IDs of products that are both recyclable and low fat.

**SQL Solution:**

```sql
SELECT product_id
FROM Products
WHERE low_fats = 'Y'
  AND recyclable = 'Y';
```

**Concepts Learned:**

- Selecting only the required column using `SELECT`.
- Filtering rows using the `WHERE` clause.
- Combining two conditions using `AND`.
- Understanding that both conditions must be true for a row to appear in the result.

**Key Takeaway:**  
Use `AND` when a record must satisfy every specified condition.

### 2. 595. Big Countries

**Topics:** `WHERE`, `OR`, Comparison Operators

**Problem Objective:**  
Find countries that qualify as big countries because their area is at least 3,000,000 square kilometres or their population is at least 25,000,000.

**SQL Solution:**

```sql
SELECT name, population, area
FROM World
WHERE area >= 3000000
   OR population >= 25000000;
```

**Concepts Learned:**

- Filtering records using numerical conditions.
- Using `>=` to include values equal to the threshold.
- Combining alternative conditions using `OR`.
- Understanding that satisfying either condition is sufficient.

**Key Takeaway:**  
Use `OR` when meeting any one of multiple conditions is enough.

---

### 3. 584. Find Customer Referee

**Topics:** `NULL` Handling, `IS NULL`, `<>`, `OR`

**Problem Objective:**  
Find the names of customers who were either not referred by customer ID 2 or have no referee recorded.

**SQL Solution:**

```sql
SELECT name
FROM Customer
WHERE referee_id <> 2
   OR referee_id IS NULL;
```

**Concepts Learned:**

- Checking for missing values using `IS NULL`.
- Understanding that `NULL` represents an unknown or missing value.
- Learning that `referee_id = NULL` is not the correct way to check for missing values.
- Understanding why `referee_id <> 2` alone does not include rows where `referee_id` is `NULL`.
- Combining conditions using `OR` to include both qualifying cases.

**Key Takeaway:**  
In SQL, use `IS NULL` to check for missing values and `IS NOT NULL` to check for non-missing values.

For this problem, the `OR referee_id IS NULL` condition is essential because a comparison with `NULL` does not evaluate to `TRUE`.

## 📚 Important SQL Rules to Remember

### 1. `AND` vs. `OR`

| Operator | Meaning |
|---|---|
| `AND` | All conditions must be true. |
| `OR` | At least one condition must be true. |

Example:

```sql
-- Both conditions must be satisfied
WHERE low_fats = 'Y'
  AND recyclable = 'Y';

-- Either condition can be satisfied
WHERE area >= 3000000
   OR population >= 25000000;
```

### 2. Comparison Operators

| Operator | Meaning |
|---|---|
| `=` | Equal to |
| `<>` | Not equal to |
| `>` | Greater than |
| `<` | Less than |
| `>=` | Greater than or equal to |
| `<=` | Less than or equal to |

### 3. Handling `NULL`

```sql
-- Find rows where a value is missing
WHERE referee_id IS NULL;

-- Find rows where a value is present
WHERE referee_id IS NOT NULL;
```

**Important:** Do not use `= NULL` or `<> NULL` to test for missing values. Use `IS NULL` or `IS NOT NULL`.
